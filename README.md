# 🧟 Necrovia

Atmospheric survival horror game made with Unity.

---

## 🎮 About the Project

**Necrovia** is a third-person survival horror game set in a post-apocalyptic world заражённого города.

Игроку предстоит:

* выживать среди заражённых
* исследовать локации
* сражаться с зомби
* раскрыть тайну вируса NX-13

Проект разрабатывается как **портфолио Unity-разработчика**.

---

## ✨ Features

* 🔹 Player movement system
* 🔹 Mouse-based aiming
* 🔹 Zombie AI (NavMesh)
* 🔹 Combat system
* 🔹 Animation system (Idle / Run / Attack)
* 🔹 Spawn system
* 🔹 Survival gameplay elements
* 🔹 Git LFS for large assets

---

## 🛠 Tech Stack

* Unity (URP)
* C#
* Git + Git LFS

---

## 📂 Project Structure

```
Assets/            - game content
Packages/          - Unity packages
ProjectSettings/   - project configuration
```

Unity-generated folders are excluded via `.gitignore`.

---

## 🚀 How to Run

1. Clone repository:

```bash
git clone https://github.com/KixMora/Necrovia.git
```

2. Open project via **Unity Hub**

3. Press ▶ Play

---
